# 连续登录天数

## 背景故事
你是某大数据平台的数仓开发工程师，运营同学想筛选出高活跃用户，用于发放连续登录奖励。连续登录统计是大数据 SQL 面试中非常常见的题型，核心思路是用窗口函数识别连续日期分组。

## 数据说明
登录日志表 `user_login_log` 记录了用户每天的登录行为：

- `user_id`：用户 ID
- `login_date`：登录日期

## 任务要求
请编写 SQL 查询，统计每个用户的最长连续登录天数：

1. 同一用户相邻登录日期差 1 天，视为连续登录
2. 返回每个用户的最长连续登录天数
3. 返回字段：用户 ID（user_id）、最长连续登录天数（max_continue_days）
4. 按最长连续登录天数降序、用户 ID 升序排列

## 提示
- 先对每个用户按登录日期排序，使用 `ROW_NUMBER()` 生成序号
- 连续日期减去相同序号后会得到相同的分组标识
- SQLite 可以使用 `DATE(login_date, '-' || rn || ' day')` 计算分组标识
