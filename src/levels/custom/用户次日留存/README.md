# 用户次日留存

## 背景故事
你负责分析 App 的用户增长效果，产品经理想知道每天新增用户中，有多少人在第二天仍然活跃。次日留存率是互联网和大数据岗位面试中的高频指标题。

## 数据说明
用户行为表 `app_user_action` 记录了用户活跃日期：

- `user_id`：用户 ID
- `action_date`：活跃日期

用户第一次活跃的日期视为新增日期。

## 任务要求
请编写 SQL 查询，统计每天新增用户的次日留存情况：

1. 找出每个用户的新增日期（第一次活跃日期）
2. 判断用户是否在新增日期的第二天仍然活跃
3. 返回字段：新增日期（dt）、新增用户数（new_users）、次日留存用户数（retained_users）、次日留存率（retention_rate）
4. `retention_rate` 保留 2 位小数，按百分比数值展示，例如 `66.67`
5. 按新增日期升序排列

## 提示
- 先用 `MIN(action_date)` 得到每个用户的新增日期
- 再用 `LEFT JOIN` 匹配第二天活跃记录
- SQLite 中可以使用 `DATE(first_date, '+1 day')` 计算次日
