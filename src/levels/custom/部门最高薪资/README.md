# 部门最高薪资

## 背景故事
你需要为 HR 报表查询每个部门薪资最高的员工。如果最高薪资有并列，需要全部返回。这类分组取最大值的题目在面试中非常高频。

## 数据说明
部门员工表 `department_employee`：

- `employee_id`：员工 ID
- `employee_name`：员工姓名
- `department_name`：部门名称
- `salary`：薪资

## 任务要求
请编写 SQL 查询，返回每个部门薪资最高的员工：

1. 如果同部门多人并列最高薪资，需要全部返回
2. 返回字段：部门名称（department_name）、员工姓名（employee_name）、薪资（salary）
3. 按部门名称升序、员工 ID 升序排列

## 提示
- 可以用窗口函数 `RANK()` 给部门内薪资排名
- 也可以用子查询关联每个部门的最高薪资
