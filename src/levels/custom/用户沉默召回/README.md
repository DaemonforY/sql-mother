# 用户沉默召回

## 背景故事
你负责用户召回策略，需要找出在统计日之前已经沉默较久的用户。沉默用户筛选是用户增长和数据分析面试中的常见题。

## 数据说明
用户活跃日志表 `user_active_log`：

- `user_id`：用户 ID
- `active_date`：活跃日期

假设统计日期为 `2024-08-01`。

## 任务要求
请编写 SQL 查询，找出截至 `2024-08-01` 已经连续 7 天及以上未活跃的用户：

1. 先统计每个用户最后一次活跃日期
2. 计算统计日期与最后活跃日期的间隔天数
3. 只返回沉默天数大于等于 7 的用户
4. 返回字段：用户 ID（user_id）、最后活跃日期（last_active_date）、沉默天数（silent_days）
5. 按沉默天数降序、用户 ID 升序排列

## 提示
- 使用 `MAX(active_date)` 统计最后活跃日期
- SQLite 可用 `JULIANDAY('2024-08-01') - JULIANDAY(last_active_date)` 计算日期差
