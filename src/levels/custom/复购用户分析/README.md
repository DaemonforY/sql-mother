# 复购用户分析

## 背景故事
你是电商业务的数据分析师，运营团队希望统计用户复购情况，判断活动是否提升了用户重复购买意愿。复购率是电商 SQL 面试中的常见指标。

## 数据说明
订单表 `user_orders` 记录了用户订单：

- `order_id`：订单 ID
- `user_id`：用户 ID
- `order_date`：下单日期
- `order_amount`：订单金额

## 任务要求
请编写 SQL 查询，统计平台整体复购情况：

1. 下单次数大于等于 2 的用户视为复购用户
2. 返回总下单用户数（total_users）
3. 返回复购用户数（repurchase_users）
4. 返回复购率（repurchase_rate），保留 2 位小数，按百分比数值展示

## 提示
- 先按 `user_id` 聚合订单次数
- 再用 `CASE WHEN` 统计复购用户
